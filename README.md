# AMNU

A minimal dynamic menu and application launcher for wayland inspired by dmenu.  

Designed for use with ANVL, but works with any Wayland compositor implementing the layer-shell protocol.  

## Mirrors
- [github](https://github.com/Auoggi/amnu)
- [codeberg](https://codeberg.org/auoggi/amnu)  

## Build Dependencies

- fd
- gcc
- make
- pkgconfig
- wayland
- xkbcommon
- pixman
- fcft

## Build

```bash
make build
```
